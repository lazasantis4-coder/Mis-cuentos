# 🚀 Mundo Mágico

¡Una aplicación web interactiva y gamificada diseñada para niños y niñas! Cuenta con 20 historias cortas, sistema de puntos en vivo, trivias dinámicas y soporte para convertirse en PWA (Aplicación Web Progresiva instalable en el celular).

## ✨ Características Principales
* **20 Historias Interactivas:** Contenido visual y dinámico para mantener una alta retención de usuarios.
* **Sistema de Puntos y Retos:** Los usuarios suman puntos al avanzar de historia y responder trivias, aumentando el tiempo de permanencia en la web.
* **Diseño Responsivo (Mobile-First):** Optimizado para verse perfecto en pantallas de teléfonos celulares (ideal para tráfico de TikTok).
* **Instalable (PWA):** Incluye `manifest.json` y `service.worker.js` para que los usuarios puedan añadirlo directamente a su pantalla de inicio.
* **Monetización Amigable:** Espacios estratégicos para banners publicitarios que no interfieren con la experiencia del usuario.

## 🛠️ Tecnologías Utilizadas
* **HTML5 / CSS3**
* **Tailwind CSS** (vía CDN)
* **JavaScript Moderno**
* **Service Workers & PWA Manifest**

## 🚀 Despliegue
Este proyecto está optimizado para ser alojado y desplegado de manera automática mediante **Vercel** conectado directamente a este repositorio de **GitHub**.
